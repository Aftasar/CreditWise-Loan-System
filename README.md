# CreditWise-Loan-System
CreditWise Loan System
Project Description

CreditWise Loan System is an end-to-end supervised machine learning project designed to predict loan approval outcomes using binary classification techniques. The project implements and compares three machine learning algorithms: K-Nearest Neighbors (KNN), Logistic Regression, and Naïve Bayes.

The workflow includes Exploratory Data Analysis (EDA), data preprocessing, feature engineering, model training, and performance evaluation. The models are evaluated using key classification metrics, including Precision, Recall, and F1-Score, to assess their predictive performance.

Key Features
Exploratory Data Analysis (EDA) to identify patterns and relationships in the data.
Data preprocessing and feature engineering to prepare the dataset for modeling.
Implementation of KNN, Logistic Regression, and Naïve Bayes classifiers.
Binary classification to predict loan approval outcomes.
Model evaluation using Precision, Recall, and F1-Score.
Technologies Used
Python
Pandas and NumPy
Scikit-learn
Matplotlib and Seaborn
Jupyter Notebook
Objective

The primary objective is to develop and evaluate supervised machine learning models that can predict loan approval outcomes based on applicant data and compare their classification performance.

Dataset

The dataset is used for data exploration, preprocessing, feature engineering, and model development. Dataset files are excluded from version control using .gitignore and are not included in this repository.
